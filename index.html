04 — PROJECTS

Things I've Built

01

FEATURED PROJECT · HAL PROJECT

PatchPoint

AI-Enhanced Pothole Detection & Monitoring System

A HAL project focused on developing an AI-enhanced pothole detection and monitoring system using sensor fusion between LiDAR and camera data, integrated with a Raspberry Pi platform.

The system processes road imagery and depth information to identify potholes, classify road conditions, assess severity, and support proactive road maintenance through a monitoring dashboard.

Camera → Computer Vision → Raspberry Pi → GPS / LiDAR → Backend → Dashboard
Python OpenCV CNN React.js Node.js Express.js MongoDB Raspberry Pi
GitHub ↗ HAL Certificate ↗
02

COMPUTER VISION + HARDWARE

PainSight

AI-Integrated Pain Detection-Based Syringe Infusion Pump

A low-cost AI-powered syringe infusion pump concept designed to automate fluid injection based on patient pain detection.

The system uses a camera to capture facial expressions and a fine-tuned MobileNet model to classify pain levels in real time. The detected condition can then trigger an Arduino-controlled syringe infusion pump.

Python PyTorch MobileNet OpenCV Arduino Uno Stepper Motor
GitHub ↗
03

MACHINE LEARNING + DATA SCIENCE

WeatherCast ML

Next-Day Weather Prediction

A machine learning project that predicts next-day maximum temperature and precipitation occurrence using historical weather observations.

Built a reproducible ML pipeline with temporal feature engineering, Random Forest models, chronological evaluation, and a persistence baseline. Deployed an interactive dashboard featuring live weather forecasts and model evaluation visualizations.

Python Pandas Scikit-learn Random Forest Streamlit Open-Meteo API
