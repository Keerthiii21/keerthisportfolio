# Keerthi Portfolio Refresh — certificates included

This package includes the refreshed portfolio website plus the certificate PDFs linked from the Certificates section.

## Files
- `index.html` — page structure and portfolio content
- `style.css` — responsive styling and larger, readable text
- `script.js` — mobile navigation and reveal animations
- `certificates/` — the certificate PDFs linked from the website

## Run locally in VS Code
1. Extract the ZIP file.
2. Open the extracted folder in VS Code using **File → Open Folder**.
3. Install the **Live Server** extension if needed.
4. Open `index.html` and click **Go Live**.
5. Keep the `certificates` folder beside `index.html`; do not move individual PDFs out of it unless you also update their links.

## Publishing on GitHub Pages
Upload `index.html`, `style.css`, `script.js`, and the complete `certificates/` folder to the repository root. Commit the changes to the branch used by GitHub Pages, then test the certificate links on the published site.
